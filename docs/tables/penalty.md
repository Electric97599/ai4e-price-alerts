# Weighted decision penalty

Weights at k = 1, 3 and 5 are assumptions, not measured procurement costs. Every rule uses its original threshold, frozen on calibration cells. The common-cell result uses the intersection of scored (series, month) pairs across the rules in each fold, making model rankings directly comparable. The covered-cell result describes each rule's own coverage and should not be ranked against other rules with different coverage. The all-cell result treats an uncovered cell as no alert, counting an actual rise as missed. Every row reports its denominators; lower penalty is better.
